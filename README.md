# Kenny’s personal lab

[Visit the site](https://kennymcsimpson.github.io/) · [Field notes](https://kennymcsimpson.github.io/notes/) · [RSS](https://kennymcsimpson.github.io/feed.xml)

A small, bilingual personal website about research, code, and lasting context. The interactive constellation introduces Ecosystem, PI-Ecosystem, and Lyra. PI is in local development; its source is not public yet.

The site uses plain HTML, CSS, and JavaScript. No build step, external API, analytics, or dependency installation is required. Serve this directory over HTTP with a static server to preview it. GitHub Pages publishes `main` from the repository root.

- `index.html`, `app.js`: constellation, workflows, current focus, and open-source contributions.
- `notes/`, `reading.js`: bilingual notes and reading navigation.
- `common.js`, `preferences.js`: shared search, language, and theme controls.
- `styles.css`, `enhancements.css`: presentation and responsive layouts.
- `feed.xml`, `sitemap.xml`: subscription and discovery.

Contribution counts are a dated snapshot, with links to the merged upstream PRs. Lyra’s notes on the homepage are prewritten text.
