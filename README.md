# kennymcsimpson.github.io

[Visit the site](https://kennymcsimpson.github.io/) · [Projects](https://kennymcsimpson.github.io/projects/) · [Ecosystem 1.0](https://kennymcsimpson.github.io/ecosystem/) · [Now](https://kennymcsimpson.github.io/now/) · [Notes](https://kennymcsimpson.github.io/notes/) · [RSS](https://kennymcsimpson.github.io/feed.xml)

Kenny’s personal site, in English and Chinese: an illustrated workbench, open-source software spun out of daily work, public research archives, an interactive Ecosystem 1.0 map, a now page, and field notes. PI is his personal fork of the open-source [PI Desktop](https://github.com/AR307/PI-Desktop); his personal build remains local.

Plain HTML, CSS and a little JavaScript. No framework, build step, web font or dependency; illustrations use inline SVG. GitHub Pages publishes `main` from the repository root. To preview, serve this directory with any static server.

| File | What it holds |
| :-- | :-- |
| `index.html` | Home: illustrated workbench, open-source &amp; research showcase, Ecosystem 1.0 preview, now, notes, and contact postcard |
| `projects/` | Full open-source catalog (multi-agent tools, offline desktop apps), research archive, upstream links, and lab bench |
| `ecosystem/` | Interactive Ecosystem 1.0 map (11 nodes), an ordinary day, and public vs. local boundaries |
| `now/`, `uses/`, `notes/` | Current work, daily tools, and bilingual field notes |
| `assets/` | Favicon |
| `styles.css` | Layout, drawing styles, day and night colours, and reduced motion |
| `prefs.js`, `site.js` | Language, theme, legacy links, and the Ecosystem map |
| `404.html`, `feed.xml`, `sitemap.xml` | Not-found page, RSS feed, and sitemap |

Both languages live in the same page as `data-l="en"` / `data-l="zh"` pairs. Language follows the browser unless chosen with the switch or `?lang=en` / `?lang=zh`; theme follows the system unless chosen at the bottom of the page.
