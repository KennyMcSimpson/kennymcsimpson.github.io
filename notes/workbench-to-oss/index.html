Spinning quiet tools out of a private workbench从私有工作台里拆出安静的开源工具

A personal workbench is full of local habits, accounts, and history. The parts worth sharing are the sharp instruments inside it.

私人工作台里装满了个人习惯、账号和历史记录；真正值得拿出来共享的，是里面打磨顺手的一件件单用途工具。

Why not open-source the whole desk?为什么不直接把整张工作台打包开源？

A real daily workbench accumulates private wiring fast: memory files, credentials, local machine conventions, unpublished research notes. Publishing the whole thing as a monolith would either leak what should stay private or turn into a fragile template nobody else can actually run.

一个每天真的在用的工作台，很快就会长满私人脉络：个人记忆、本机约定、账号配置和未发表的研究草稿。如果硬把整座房子打包扔上 GitHub，要么漏掉不该公开的东西，要么变成别人根本跑不起来的脆弱大杂烩。

What travels well instead are the individual instruments — small tools forged by real friction, stripped down to one clear boundary.

真正能跨出我这张书桌的，是里面被真实痛点逼出来的单用途工具——边界干净、拿去就能用。

Six pieces that earned their own repositories六个长出独立仓库的零件

  • AgentRoundtable grew when Claude Code, Codex, and Antigravity needed to sit at the same table without wrapping them in another bloated framework. Zero dependencies, plain JOIN.md seats, and artifact freeze gates.AgentRoundtable 源于让 Claude Code、Codex 与 Antigravity 同桌协作的需求——不套重型框架，零依赖、纯 JOIN.md 席位协议加产物冻结闸门。
  • AgentTokenMeter came from wanting to know where prompt cache hits, cache writes, and equivalent API costs actually went across all three coding agents — locally, without shipping logs anywhere.AgentTokenMeter 源于想知道三端编码代理的缓存命中、写入开销和官方折算成本究竟花在了哪——全在本地算，不把日志发往任何服务器。
  • ContextRelay arrived as a zero-UI native /fork plugin for Google Antigravity — deterministically denoising long threads with zero LLM calls, syncing renamed sidebar titles, and anchoring handoffs directly to real Git diffs.ContextRelay 是面向 Google Antigravity 的原生零 UI /fork 插件——零模型调用确定性去噪长会话、同步侧边栏重命名标题，并把交接锚定到真实 Git 差异。
  • Unarmored began as lightweight hooks to strip boilerplate theatre and keep six different frontier model families speaking like honest peers across long turns.Unarmored 起初是一组轻巧钩子，用来去掉套话与表演腔，让六大前沿模型家族在长对话里保持平视、诚实的同伴语气。
  • Inkglass solved a specific frustration: agents edit Markdown specs and research notes constantly, and opening them in a full editor risks accidental overwrites. A read-only offline reader with live diff-watch turned out to be something I open dozens of times a day.Inkglass 解决的是一个很具体的烦恼：代理频繁改写方案和研究文档，用编辑器打开总怕手误覆盖。一个只读、离线、带实时差异高亮的阅读器，成了我每天打开几十次的软件。
  • Edgewise started because full calendar apps were either noisy or invisible when sharing my screen. A 46 px offline edge strip that vanishes from screen captures and lets clicks pass through stays out of the way until a deadline actually approaches.Edgewise 来自对臃肿日程软件的厌倦：一条 46 px 的离线贴边栏，共享屏幕时自动隐身、支持点击穿透，平时几乎不存在，临近截止才会安静提醒。

Three rules they all share它们共同守着的三条底线

Looking back across all six releases, the same habits carried over from Ecosystem 1.0: offline by default (nothing phones home), minimal dependencies (standard library or zero runtime deps wherever practical), and predictable boundaries (read-only where reading is intended, explicit approval before irreversible steps).

回头看这六款软件，其实带着同一套来自 Ecosystem 1.0 的癖好：默认离线（绝不偷偷联网上报）、极简依赖（能用标准库或零运行依赖绝不堆包）、边界清楚（只读就是只读，不可逆动作必先确认）。
