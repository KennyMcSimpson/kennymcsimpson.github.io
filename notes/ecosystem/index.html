Ecosystem、PI 与 Lyra，各自在做什么？

一套工作方式、一个桌面工作区，以及其中正在完善的搭档。把这几个名字放回它们的位置。

先从工作里那些断掉的线说起

一个问题可能始于论文，接着变成笔记、代码和实验。隔一段时间再回来，最费劲的往往是找回上下文：上次为什么选这个方案，试过哪些办法，那个结果又来自哪里。

Ecosystem 从这些日常的断点出发。它把项目记忆、科研、编码和工具连接放在同一套工作方式里，让一次任务产生的线索，能在下一次继续派上用场。

Ecosystem→PI-Ecosystem↔Lyra

三个名字，三个位置

Ecosystem 是整体的组织方式。项目记忆保留状态、决定和来源；科研与独立评审分别组织研究和评价；编码执行让具体改动与检查发生；技能和工具连接把外部能力接进来。

PI-Ecosystem 是桌面工作区。它为这些模块提供一个共同的落脚处，让不同工作流程能在一个环境里相遇。名字相近，是因为 PI 承载着这套 Ecosystem 的具体实现。

Lyra 是其中正在完善的管家与搭档。她是人与这个工作环境之间的一个入口，也给工具多一点可以相处的性格。

落到一天的工作里

做研究时，问题和证据一路走向方案、实验和验证，再交给独立的评价。写代码时，先读懂现有实现，做一块范围清楚的改动，再运行相关检查。隔天接着做时，先找回状态，再核对眼前的文件和结果。

这些流程都需要一些共同的东西：能找回的上下文，能回到的来源，以及足够具体的下一步。首页的星图试着把这些联系画出来。

现在到哪一步了

截至 2026 年 10 月 31 日，PI-Ecosystem 仍在本地开发，源码尚未公开。各模块和 Lyra 都在继续完善。

这个网站先把结构和想法摆出来。等 PI 适合公开时，这里会接上源码、实际界面和更完整的使用记录。现在可以先从记忆这颗星开始，或者去看看 Lyra。

Start with the loose threads

A question might start in a paper, become a note, then turn into code and an experiment. Coming back later often means reconstructing the context: why this approach, what has already been tried, and where that result came from.

Ecosystem starts with those everyday gaps. It brings project memory, research, coding, and tool connections into a shared way of working, so a thread left by one task can still be useful in the next.

Ecosystem→PI-Ecosystem↔Lyra

Three names, three places

Ecosystem is the overall organization. Project memory retains state, decisions, and sources. Research and independent review organize the work and its evaluation separately. Coding and execution make concrete changes and checks happen. Skills and tool integrations connect outside capabilities.

PI-Ecosystem is the desktop workspace. It gives those modules a common home, where different workflows can meet. The names are close because PI carries the concrete implementation of this Ecosystem.

Lyra is the companion taking shape inside it. She offers an entry point between a person and this working environment, with a little personality along the way.

In the course of a day

Research moves from a question and its evidence toward a plan, an experiment, validation, and independent evaluation. Coding starts with the existing implementation, makes a scoped change, and runs the relevant checks. Picking up tomorrow starts by recovering the state and checking the actual files and results.

These workflows share a few needs: context that can be recovered, sources that can be revisited, and a concrete next step. The constellation on the homepage tries to draw those connections.

Where it stands

As of October 31, 2026, PI-Ecosystem is in local development and its source is not public yet. The modules and Lyra are still evolving.

This website is a first look at the structure and the ideas. When PI is ready to share, it will link to the source, actual interface, and a fuller account of using it. For now, start with the memory star, or meet Lyra.
