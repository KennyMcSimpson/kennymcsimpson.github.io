Ecosystem, PI and Lyra: how do they fit?Ecosystem、PI 与 Lyra，各自在做什么？

A workbench I use every day, the habits that grew around it, and the assistant who lives inside.

一个每天在用的工作台，围着它长出来的一圈习惯，以及住在里面的助手。

Start with the loose threads先从断掉的线说起

A question might start in a paper, become a note, then turn into code and an experiment. Coming back later often means reconstructing the context: why this approach, what has already been tried, and where that result came from.

一个问题可能始于论文，接着变成笔记、代码和实验。隔一段时间再回来，最费劲的往往是找回上下文：上次为什么选这个方案，试过哪些办法，那个结果又是从哪里来的。

The Ecosystem starts with those everyday gaps. It isn’t a product. It is a set of habits I built, bit by bit, around one workbench.

Ecosystem 从这些日常的断点出发。它不是一个产品，而是我围着一个工作台，一点点搭出来的一套习惯。

Three names, three places三个名字，三个位置

PI is the workbench. It is my own build of the open-source PI Desktop, an Electron AI workbench, and it is open all day.

PI 是工作台。它是我基于开源项目 PI Desktop（一个 Electron AI 桌面工作台）改出来的个人版本，每天都开着。

The Ecosystem is what grew around it. Scheduled jobs deliver a daily paper digest, a GitHub report and a group-chat digest, distill memory, and run a health check once a week. Research mode handles focused questions; bigger ones go to the “institution”, run by separate roles: a director, reviewers and a council. PI Chrome is a controlled browser for the agents. The reading workspace puts Zotero and Obsidian next to the conversation. Claude Code and Codex write code. Holding it together is a set of rules about state files and releases.

Ecosystem 是围着它长出来的一圈。定时任务按时送来每日论文摘要、GitHub 报告和群聊摘要，做记忆整理，每周再做一次健康检查；研究模式处理聚焦的问题，更大的交给“研究院”，由主持、评审和评审会分角色来跑；PI Chrome 是给代理用的受控浏览器；阅读区把 Zotero 和 Obsidian 放到对话旁边；Claude Code 和 Codex 负责写代码。把它们串起来的，是一套关于状态文件和发布的规矩。

Lyra is the assistant who lives inside. She has her own window, memory notebook and reminders, and she acts on my behalf. Only irreversible or outward actions, such as permanent deletion, spending, or messaging someone, wait for my yes.

Lyra 是住在里面的助手。她有自己的窗口、记忆本和提醒，可以替我动手。只有不可逆或对外的操作，比如永久删除、花钱、对外发消息，她会先问我。

In the course of a day落到一天的工作里

The digests arrive early; papers get read in the side panel in the morning; daytime is for writing code with the agents, with web steps going through PI Chrome; big questions go to the institution; in the evening, memory distillation tidies up the day’s threads. How a day runs draws that line.

清晨，摘要先到；上午在侧栏里读论文；白天和编码代理一起写代码，需要上网的步骤交给 PI Chrome；遇到大问题，交给研究院；晚上，记忆整理把一天的线索收好。“一天”把这条线画了出来。

Where it stands现在到哪一步了

As of 2026-11-03: PI, Lyra, the scheduled jobs, PI Chrome and the reading workspace are in daily use; the institution is still being built. My PI build is not released. It is wired to my own machine and accounts, with no installer or docs. PI Desktop itself is open source.

截至 2026-11-03：PI、Lyra、定时任务、PI Chrome 和阅读区每天都在用；研究院还在建设中。我的 PI 构建没有公开发布，它连着我自己的机器和账号，没有安装包和文档。PI Desktop 本身是开源的。

If a piece becomes something other people can use, it will show up here first. For now, there is a drawing of the whole thing.

如果哪一部分变成别人也能用的东西，会先出现在这里。现在可以先看看整张图。
