Ecosystem, PI and Lyra: how do they fit?Ecosystem、PI 与 Lyra，各自在做什么？

A workbench I use every day, the 11-department habits that grew around it, and the steward who lives inside.

一个每天在用的工作台，围着它长出来的 11 个机构与习惯，以及住在里面的大管家。

Start with the loose threads先从断掉的线说起

A question might start in a paper, become a note, then turn into code and an experiment. Coming back later often means reconstructing the context: why this approach, what has already been tried, and where that result came from.

一个问题可能始于论文，接着变成笔记、代码和实验。隔一段时间再回来，最费劲的往往是找回上下文：上次为什么选这个方案，试过哪些办法，那个结果又是从哪里来的。

Ecosystem 1.0 starts with those everyday gaps. It isn’t a product. It is a set of habits and department boundaries I built, bit by bit, around one workbench.

Ecosystem 1.0 从这些日常的断点出发。它不是一个产品，而是我围着一个工作台，一点点搭出来的机构分工与日常习惯。

Three names, three places三个名字，三个位置

PI is the workbench. It is my own build of the open-source PI Desktop, an Electron AI workbench, and it is open all day.

PI 是工作台。它是我基于开源项目 PI Desktop（一个 Electron AI 桌面工作台）深度改造的个人版本，每天都开着。

Ecosystem 1.0 is what grew around it. Instead of organising by tool, it divides daily work into 11 departments — stewarding, repair, central memory (with a compact ~8 KB Gallery index), research, an isolated blind review council, reading & library, skills, plugins, and a 4-agent roundtable where PI hosts Claude Code, Codex, and Antigravity. Ticket locks, critical file locks, safe recycle-bin deletion, and automated self-checks keep parallel agents from colliding.

Ecosystem 1.0 是围着它长出来的一整套生态。它不再按工具切分，而是按职能划成 11 个分工机构——大管家、修理间、中央记忆与 8 KB 展厅、研究院、独立双盲评议会、文献与阅读、技能与插件，以及由 PI 主持、Claude Code / Codex / Antigravity 同桌协作的四代理圆桌。工单占用锁、关键文件锁、删前四步回收站与自动自检，保证多代理并行干活时不互相打架。

Lyra is the steward who lives inside. She has her own window, memory stewardship, and reminders, and she acts on my behalf across departments. Irreversible, high-cost, or outward actions always pause and wait for my yes.

Lyra 是住在里面的大管家。她有自己的窗口、记忆统筹权限与提醒，可以跨机构替我协调事务。但凡涉及不可逆、高成本或对外的动作，一律先停下来等我确认。

In the course of a day落到一天的工作里

The digests arrive early and the Gallery keeps every agent oriented; papers get read in Zotero and Inkglass in the morning; daytime is for coding across Claude Code, Codex, and Antigravity with PI Chrome guarding web steps; deeper questions go to the roundtable or the blind research council; in the evening, memory distillation and the token ledger tidy up the day’s threads. How a day runs draws that line.

清晨，摘要先到，展厅让每个代理开场对齐背景；上午在 Zotero 与 Inkglass 里读论文和活跃文档；白天三端编码代理并行写代码，需要上网的步骤走 PI Chrome 确认；复杂问题交给圆桌或双盲评议会；夜里，记忆提炼与用量账本把一天的线索收口。“一天”把这条线画了出来。

Where it stands现在到哪一步了

As of 2026-11-25: Ecosystem 1.0 is running end-to-end, including the 4-agent roundtable and the blind research council. My personal PI build remains local — wired to my machine and private memory — while six clean, general-purpose pieces have already been extracted into standalone open-source software: AgentRoundtable, AgentTokenMeter, ContextRelay, Unarmored, Inkglass, and Edgewise.

截至 2026-11-25：Ecosystem 1.0 已全面跑通，包括四代理圆桌与双盲评议会。个人 PI 构建仍然留在本地，与本机环境和私人记忆绑定；但其中六块通用、干净的能力已经逐一拆出，公开发布在 开源作品页：AgentRoundtable、AgentTokenMeter、ContextRelay、Unarmored、Inkglass 与 Edgewise。
