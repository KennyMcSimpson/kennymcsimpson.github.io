What I use, and how this site is made.每天用的东西，
和这个网站的做法。

Only the things I actually open every day. No affiliate links, no sponsors.

只列真正每天在开的东西。没有推荐链接，也没有赞助。

Every day每天

Workbench工作台

PI, my own build of the open-source PI Desktop (Electron), on Windows. Not released.

PI，我基于开源的 PI Desktop（Electron）改的个人构建，跑在 Windows 上。未公开发布。

Assistant助手

Lyra, inside PI, with her own window, memory notebook and reminders.

Lyra，住在 PI 里，有自己的窗口、记忆本和提醒。

Coding agents编码代理

Claude Code and Codex, for everyday code and for building PI itself.

Claude Code 和 Codex，日常写代码，也用来开发 PI 本身。

Browser for agents给代理的浏览器

PI Chrome: confirmation cards, an audit log, and a read-only mirror in the work panel.

PI Chrome：确认卡、审计日志、工作面板里的只读镜像。

Reading & notes阅读与笔记

Zotero for papers and PDF annotations, Obsidian for notes, both opened in PI’s side panel.

文献和 PDF 批注在 Zotero，笔记在 Obsidian，两者都在 PI 的侧栏里打开。

Code代码

Git and GitHub. Upstream contributions go through a fork and a pull request.

Git 和 GitHub。上游贡献走 fork 加 PR。

This site这个网站

Built with写法

Hand-written HTML and CSS, and a little JavaScript for the language switch, the theme and the drawing. No framework, no build step, no dependencies.

手写的 HTML 和 CSS，加一点 JavaScript 负责语言切换、主题和那张图。没有框架，没有构建步骤，没有依赖。

Type字体

System fonts only. Headings in your system’s serif (New York, Iowan, Sitka or Georgia; Songti or Noto Serif for Chinese), text in its sans (Segoe UI, PingFang, Microsoft YaHei), dates in its monospace.

只用系统字体。标题用衬线体（New York、Iowan、Sitka 或 Georgia；中文用宋体或思源宋体），正文用无衬线体（Segoe UI、苹方、微软雅黑），日期用等宽字体。

Colour颜色

Warm paper, near-black ink, and one vermilion accent, the colour of a seal. Dark mode follows your system unless you pick one at the bottom of the page.

暖白的纸、近黑的墨，再加一种朱红，像印章的颜色。深色模式跟随系统，也可以在页面底部手动选。

Privacy隐私

No analytics, no cookies, no requests to anyone else. Your language and theme choices stay in your own browser.

没有统计、没有 cookie，也不请求任何第三方资源。语言和主题的选择只存在你自己的浏览器里。

Two languages两种语言

English and Chinese live on the same page. It follows your browser’s language; switch at the top, or add ?lang=zh to a link.

中文和英文写在同一页里，默认跟随浏览器语言；可以在页面顶部切换，也可以在地址后加 ?lang=en。

Borrowed from借鉴

The quiet single column, the vermilion accent and the monospace dates of blog.eigentime.org; the name-and-a-line index rows of sayori.org; the one-line status of SlowMo; the warm paper of qianling.pw; and the now page idea from Derek Sivers.

安静的单栏、朱红的点缀色和等宽日期，来自 blog.eigentime.org；“名字加一句话”的索引行，来自 sayori.org；一行状态，来自 SlowMo；暖白的纸，来自 qianling.pw；now 页的想法来自 Derek Sivers。

Made with制作

Written together with coding agents. The source is on GitHub.

和编码代理一起写的。源码在 GitHub。
