What I use, and how this site is made.我用什么，以及这个网站怎么做的。

Only what I open every day. No affiliate links.

只列每天真的会打开的东西。没有推广链接。

Every day每天

  • Workbench工作台

    PI, my build of the open-source PI Desktop (Electron), on Windows. Not released.

    PI，我基于开源 PI Desktop（Electron）的个人构建，跑在 Windows 上。未发布。

  • Assistant助手

    Lyra, inside PI, with her own window, memory notebook and reminders.

    Lyra，住在 PI 里，有自己的窗口、记忆本和提醒。

  • Coding agents编码代理

    Claude Code and Codex, for everyday code and for building PI itself.

    Claude Code 和 Codex，写日常代码，也用来改 PI 本身。

  • Browser for agents代理的浏览器

    PI Chrome: confirmation cards, an audit log, a read-only mirror.

    PI Chrome：确认卡片、审计日志、只读镜像。

  • Reading & notes阅读与笔记

    Zotero for papers and PDF notes, Obsidian for notes, both in PI’s side panel.

    Zotero 管论文和 PDF 批注，Obsidian 记笔记，都开在 PI 的侧栏里。

  • Code代码

    Git and GitHub. Upstream fixes go through a fork and a pull request.

    Git 和 GitHub。交回上游的修复都走 fork 和 PR。

This site这个网站

  • Built with用什么做的

    Plain HTML and CSS, a little JavaScript. No framework, no build step, no dependencies.

    纯 HTML 和 CSS，加一点 JavaScript。没有框架、构建步骤和依赖。

  • Drawings插画

    Every picture is inline SVG drawn for this site.

    每一张图都是为这个网站画的内联 SVG。

  • Type & colour字体与颜色

    System fonts. Paper and ink by day, night blue by night; amber, vermilion, teal.

    只用系统字体。白天是纸和墨，夜里是夜蓝；点缀琥珀、朱红、青绿。

  • Privacy隐私

    No analytics, no cookies. Only the contributor avatars load from GitHub.

    没有统计，没有 cookie。只有贡献页的头像从 GitHub 加载。

  • Two languages两种语言

    English and 中文 on the same page; add ?lang=zh to a link.

    中英文在同一页；链接后加 ?lang=zh 即可。

  • Made with一起做的

    Written together with coding agents. Source on GitHub.

    和编码代理一起写的。源码在 GitHub。
