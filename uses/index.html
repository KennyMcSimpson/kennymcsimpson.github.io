Every day每天

  • Workbench & Steward工作台与大管家

    PI (my personal build of PI Desktop on Windows) and Lyra, governing 11 departments inside Ecosystem 1.0.

    PI（Windows 上的个人版 PI Desktop）与常驻大管家 Lyra，在 Ecosystem 1.0 里统筹 11 个分工机构。

  • Coding agents三端编码代理

    Claude Code, Codex, and Antigravity — collaborating via AgentRoundtable, metered by AgentTokenMeter, and calibrated with Unarmored.

    Claude Code、Codex 与 Antigravity——通过 AgentRoundtable 同桌协作，用 AgentTokenMeter 记账，用 Unarmored 校准语域。

  • Own desktop tools自造桌面小工具

    Inkglass for watching live Markdown docs without accidental edits; Edgewise parked at the screen edge for deadlines and 25m focus blocks.

    Inkglass 用来只读对照不断变化的 Markdown 文档；Edgewise 贴在屏幕边缘盯截止日期与 25 分钟专注块。

  • Browser for agents代理的浏览器

    PI Chrome: confirmation cards before outward actions, an audit log, and a read-only mirror in the work panel.

    PI Chrome：对外操作先弹确认卡片、全程审计日志，以及工作面板里的只读镜像。

  • Reading & notes阅读与笔记

    Zotero for papers and PDF highlights, Obsidian for long-term notes, both accessible beside PI.

    Zotero 管论文与 PDF 批注，Obsidian 管长期笔记，都可以直接开在 PI 旁边。

  • Code & version control代码与版本控制

    Git and GitHub, explicit push gates, and minimal upstream pull requests with regression tests.

    Git 与 GitHub、显式推送授权门禁，以及带回归测试的最小上游修复 PR。

This site这个网站

  • Built with用什么做的

    Plain HTML and CSS, a little JavaScript. No framework, no build step, no dependencies.

    纯 HTML 和 CSS，加一点 JavaScript。没有框架、构建步骤和依赖。

  • Drawings插画

    Every picture is inline SVG drawn for this site.

    每一张图都是为这个网站画的内联 SVG。

  • Type & colour字体与颜色

    System fonts. Paper and ink by day, night blue by night; amber, vermilion, teal, and Lyra lavender.

    只用系统字体。白天是纸和墨，夜里是夜蓝；点缀琥珀、朱红、青绿与属于 Lyra 的淡紫。

  • Privacy隐私

    No analytics, no third-party widgets, no cookies.

    没有统计，没有第三方外链卡片，没有 cookie。

  • Two languages两种语言

    English and 中文 on the same page; add ?lang=zh to a link.

    中英文在同一页；链接后加 ?lang=zh 即可。

  • Made with一起做的

    Written together with coding agents. Source on GitHub.

    和编码代理一起写的。源码在 GitHub。
