Small changes, sent upstream.小改动，交回上游。

Every pull request I’ve had merged into a public repository I don’t own: 41 of them, in 37 repositories. Most of them start the same way — reproduce the problem, add a test that fails, fix it, send it back. A few are a different kind of change (docs, a test, a CI job, one feature), and those carry a small label.

What being a contributor means“Contributor” 意味着什么

A merged pull request puts a “Contributor” label next to my name in that repository. It means the project accepted a change from me. It doesn’t mean maintainer rights, and it isn’t a job there. The useful part is behind each link: for most of them, the problem, how to reproduce it, the change, and the test that keeps it fixed.

PR 被合并后，我在那个仓库里会带上 “Contributor” 的标记。它说明项目接收了我的一次改动，不代表维护权限，也不是在那里任职。真正有用的在每条链接后面；大多数都写清了问题是什么、怎么复现、改了什么、哪个测试让它不再坏掉。
