PI WorkbenchPI 工作台 daily use每天在用

My fork of the open-source PI Desktop, an Electron AI workbench. It stays open all day and hosts Lyra, research mode, the reading side panel, and the roundtable UI.

我基于开源项目 PI Desktop（Electron AI 桌面工作台）深度改造的个人版本。整天开着，承载 Lyra、科研模式、阅读侧栏与圆桌界面。

LyraLyra 大管家 daily use每天在用

The single always-on steward across all 11 departments. She holds her own window, reminders, and memory stewardship — acting directly on routine work and asking first before anything irreversible or outward.

全生态唯一的常驻大管家，统筹 11 个分工机构的记忆与日常协调；普通事务直接代办，凡涉及不可逆、高成本或对外操作一律先问我。

Roundtable四代理圆桌 open source已抽离开源

Multi-agent collaboration room where PI hosts Claude Code, Codex, and Antigravity as external seats under shared turn governance and artifact freezes. Extracted cleanly into AgentRoundtable.

由 PI 主持、Claude Code / Codex / Antigravity 作为外部席位常驻的多代理协作房间，具备发言治理与产物冻结机制；已抽离开源为 AgentRoundtable。

PI ChromePI Chrome daily use每天在用

A controlled browser for the agents. Outward steps pause on a confirmation card, every action lands in an audit log, and a read-only mirror stays visible inside the work panel.

给代理使用的受控浏览器：对外动作先弹确认卡片，每一步写入审计日志，并在工作面板保留只读镜像。

Research & Council研究院与评议会 daily use现已跑通

Light, medium, and full-blind research modes now running end-to-end: a multi-role research engine paired with an isolated academic review council so evaluation never grades its own homework.

轻量、中量与双盲终审全档位现已跑通：多角色研究引擎与独立学术评议会彻底隔离，评审不自己给自己打分。

Reading & Library阅读与文献库 daily use每天在用

Zotero library, Obsidian notes, and paper reading right beside the conversation. The need to read living AI/research Markdown files without accidental edits later became Inkglass.

把 Zotero 文库、Obsidian 笔记与论文阅读放到对话旁边；而每天对照阅读不断变化的 Markdown 文档这一需求，后来催生了开源的 Inkglass。

Memory & Gallery中央记忆与展厅 daily use每天在用

A single-source-of-truth memory ledger organized by department rather than tool, fronted by a compact ~8 KB Gallery index that any coding agent reads in one glance before drilling down.

按机构而非按工具划分的单正本记忆库，由一份约 8 KB 的“展厅”索引开场，让任意代理一眼定位背景后再按需下钻。

Coding agents三端编码代理 daily use每天在用

Claude Code, Codex, and Antigravity share the same house rules, skill library, and memory gallery — rotating cleanly across departments without harness lock-in. Monitored locally via AgentTokenMeter and calibrated with Unarmored.

Claude Code、Codex 与 Antigravity 共享同一套总规矩、技能库与记忆展厅，跨机构轮换而不绑定单一工具；用量由 AgentTokenMeter 记账，语域由 Unarmored 校准。

Scheduled jobs定时任务 daily use每天在用

Quiet background routines on a clock: daily paper scouting, GitHub reports, memory distillation, and weekly self-checks across all departments.

按点运行的后台例行活：每日论文侦察、GitHub 日报、记忆提炼，以及覆盖全生态的每周体检。

House rules & locks总规矩与文件锁 template ready模板定稿

What keeps multi-agent work from colliding: 11 department charters, ticket-lock checkout before editing, critical file locks, 4-step recycle-bin deletion, automated self-check, and verified build swaps. Distilled into the upcoming agent-institutions Apache-2.0 template.

防止多代理互相打架的底座：11 份机构章程、改前工单占用锁、关键文件锁、删前四步与回收站机制、自动自检与核验换装。已脱敏提炼为即将开源的 Apache-2.0 模板 agent-institutions。

Spun-out OSS抽离的开源工具 6 shipped6 款开源

Six standalone tools built straight out of daily workbench needs: AgentRoundtable, AgentTokenMeter, ContextRelay, Unarmored, Inkglass, and Edgewise.

直接从日常痛点拆出来的六款独立开源软件：AgentRoundtable、AgentTokenMeter、ContextRelay、Unarmored、Inkglass 与 Edgewise。
