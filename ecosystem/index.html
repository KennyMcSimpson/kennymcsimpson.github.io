LyraLyra daily use每天在用

An always-on assistant with her own window, a memory notebook and reminders. She acts for me, and asks first only before anything irreversible or outward.

常驻的助手，有自己的窗口、记忆本和提醒。她可以替我动手；只有不可逆或对外的操作，才会先问我。

Scheduled jobs定时任务 daily use每天在用

Work on a clock: a daily paper digest, a GitHub report, a chat digest, memory distillation, and a weekly health check.

按点运行的活：每日论文摘要、GitHub 报告、群聊摘要、记忆整理，以及每周一次健康检查。

Research institution研究院 being built建设中

Research mode for focused questions. Bigger ones go to the institution: a director, reviewers and a council, with review kept apart from the research.

聚焦的问题走研究模式；更大的交给研究院：主持、评审、评审会分角色来跑，评审和研究分开。

PI ChromePI Chrome daily use每天在用

A controlled browser for the agents. Outward steps wait on a confirmation card, every step lands in an audit log, and a read-only mirror shows it in the work panel.

给代理用的受控浏览器。对外的步骤要等确认卡片，每一步都记进审计日志，工作面板里还有只读镜像。

Reading workspace阅读区 daily use每天在用

My Zotero library and Obsidian notes beside the conversation. Highlights and notes on a PDF go back to Zotero.

我的 Zotero 文库和 Obsidian 笔记就在对话旁边。PDF 上的高亮和批注会写回 Zotero。

Coding agents编码代理 daily use每天在用

Claude Code and Codex, for everyday code and for building PI itself. They work on PI from the outside.

Claude Code 和 Codex，写日常的代码，也用来改 PI 本身——它们从外面动手。

House rules规矩 daily use每天在用

What keeps it from breaking: state files are handled strictly, and a new build is built and checked before it replaces the running one.

让它不出乱子的规矩：状态文件严格处理；新构建先建好、检查过，才替换正在运行的那一个。
